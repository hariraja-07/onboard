# Barcode Scanner App — Changes Plan

## Goal
Document all changes made to build the barcode scanner Flutter app "Onboard".

## Current context
- Fresh Flutter project (counter template) at `/home/joyboy/PROJECTS/onboard`
- SDK ^3.11.0, pubspec.yaml, default widget_test.dart, standard platform dirs (android/ios/linux/macos/web/windows)
- No git repo initially; no README

## Architecture
- Single-activity Flutter app with Material Design 3
- Two screens: `HomePage` (scan/result/submit) and `ScannerPage` (camera)
- `mobile_scanner` 4.0.1 for barcode/QR detection
- Navigation via `Navigator.push<String>` for result return

## Changes

### 1. pubspec.yaml — add dependency
- Add `mobile_scanner: ^4.0.0` under `dependencies`
- Run `flutter pub get` → installs `mobile_scanner 4.0.1`

### 2. lib/main.dart — rewrite (counter → scanner app)
- Rename `MyApp` → `OnboardApp`
- Remove `MyHomePage` / `_MyHomePageState` (counter template)
- Add `HomePage` (StatefulWidget):
  - `_scannedCode` (String), `_hasScanned` (bool)
  - `_openScanner()`: pushes `ScannerPage`, awaits result, updates state
  - `_submit()`: shows `AlertDialog` with scanned code, "Scan Again" resets
  - UI: SCAN button (initial) / checkmark + code + SUBMIT (after scan)
- Add `ScannerPage` (StatelessWidget):
  - `MobileScanner` with back camera, `DetectionSpeed.normal`
  - `onDetect`: pops context with `barcode.rawValue`
- `home: const HomePage()`, `debugShowCheckedModeBanner: false`, `colorSchemeSeed: Colors.blue`

### 3. test/widget_test.dart — update test
- Replace counter test with `HomePage shows SCAN button`
- Pump `OnboardApp`, assert `find.text('SCAN')` and `find.text('Onboard')`

### 4. Git setup + push
- `git init` → `git add -A` → `git commit -m "feat: barcode scanner..."`
- `git remote add origin https://github.com/hariraja-07/onboard.git`
- `git branch -M main && git push -u origin main`
