## Architecture
- Single-page app: `HomePage` (scan/result/submit UI) + `ScannerPage` (camera view)
- Stateful `HomePage` holds `_scannedCode` and `_hasScanned` flag
- `ScannerPage` uses `MobileScanner` widget, pops result string on detection
- Navigation: `Navigator.push` → await result → update state

## Step-by-step tasks

### Task 1 — Create ScannerPage widget
- File: `lib/main.dart` (add `ScannerPage` class)
- Uses `MobileScanner` with back camera, `DetectionSpeed.normal`
- On detect: `Navigator.pop(context, barcode.rawValue)`
- Code:
```dart
class ScannerPage extends StatelessWidget {
  const ScannerPage({super.key});
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Scan Barcode'),
        backgroundColor: Colors.black, foregroundColor: Colors.white),
      body: MobileScanner(
        controller: MobileScannerController(
          detectionSpeed: DetectionSpeed.normal,
          facing: CameraFacing.back,
        ),
        onDetect: (capture) {
          for (final barcode in capture.barcodes) {
            if (barcode.rawValue != null) Navigator.pop(context, barcode.rawValue);
          }
        },
      ),
    );
  }
}
```

## Risks / tradeoffs
- `mobile_scanner` requires camera permissions on Android/iOS — not yet added to AndroidManifest/Info.plist
- Web build unsupported by mobile_scanner (camera API limitations)
- Single back camera only — no front-camera toggle
- No scan history/persistence beyond in-memory state
- Dialog dismisses on back button without resetting state
